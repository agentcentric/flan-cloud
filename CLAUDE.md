# Working on Flan Cloud

Flan is Ryan's fun/learning/portfolio project: a small self-hosted cloud. See
`README.md` for the roadmap. Learning matters as much as shipping.

## How to work with Ryan

- **Explain before building.** Walk through the design of each step in plain
  terms and get a go-ahead before writing a lot of code.
- **Go granular.** Small, focused explanations and changes. No big walls of
  text; one topic at a time.
- **Teach as you go.** Ryan knows Node.js/TypeScript well and is learning Go.
  When writing Go, briefly explain idioms that differ from TypeScript.
- **Keep it simple.** Prefer the standard library and a few well-known
  dependencies. Don't add tooling until it's needed.
- **Ask when a choice changes the design.** Make small decisions yourself and
  say what you chose.

## Git workflow

- `main` stays working. Do each piece of work on a branch and open a PR.
- Small commits with clear messages.
- Update the README roadmap when a step is finished.
